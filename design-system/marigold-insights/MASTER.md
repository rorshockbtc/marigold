## Global Rules

### Typography

- **Heading Font:** Lora (`var(--font-serif)`)
- **Body Font:** Inter (`var(--font-inter)`)
- **Base Size:** `16px` for optimal readability for older demographics
- **Line Height:** `1.8` (generous leading)
- **Letter Spacing:** Tighter for headers (`-0.02em`), looser for body (`0.01em`)

### CSS Variables & Components

The following semantic classes are defined in `globals.css` and must be used instead of inline styles:

- **`.btn-primary`**: Terracotta background, white text, 12px rounded, proper focus rings.
- **`.btn-secondary`**: White background, soft chocolate border, milk chocolate text.
- **`.input-field`**: Card background, 12px rounded, soft chocolate border.
- **`.card`**: Interaction area background, 12px rounded, subtle shadow.

**Border Radius:** Use the quirky `12px` (`0.75rem`) border radius on all interactive elements (cards, buttons, inputs).

---

## Pre-Delivery Checklist

Before delivering any UI code, verify:
- [ ] No emojis used as icons (use SVG instead: Lucide)
- [ ] Active and hover states with smooth transitions (150-300ms)
- [ ] Only use component classes (`.btn-primary`, `.card`) or standard palette variables (`bg-primary`, `text-secondary`, `bg-card-bg`). Do not use generic tailwind colors like `bg-indigo-100` or `text-slate-500`.
- [ ] Include micro-animations (`active:scale-95`) on buttons to meet UX touch-feedback rules.
